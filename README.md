HSK Story AI — wersja v6. Lokalna aplikacja do generowania tekstów po chińsku i nauki HSK.

Quick start:

1. Skopiuj `src/config.example.js` → `src/config.js` i uzupełnij `API_KEY` jeśli potrzebujesz.
2. Uruchom serwer zapisu wag (opcjonalnie): `node save_weights_server.js` w katalogu projektu.
3. Otwórz `index.html` lokalnie (np. `npx http-server -p 8005`) i odwiedź http://localhost:8005

Uwaga: nie commituj `src/config.js` ani kluczy API.
